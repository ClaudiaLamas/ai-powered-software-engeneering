Analisa o endpoint como Application Security Engineer.

1. Identifica potenciais vulnerabilidades.
2. Explica as causas e o impacto.
3. Classifica segundo categorias OWASP aplicáveis.
4. Propõe uma implementação corrigida.
5. Gera testes de acesso autorizado e não autorizado.
6. Define como validar a correção.

Não assumas que autenticação implica autorização.
Não inventes regras de acesso.
Distingue resultados inferidos dos testados.
