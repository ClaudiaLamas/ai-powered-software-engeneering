Analisa o serviço TaskService existente neste projeto e gera testes unitários utilizando a framework já configurada.

Contexto:
- Consulta os requisitos e critérios de aceitação.
- Analisa as interfaces e dependências.
- Respeita as convenções do projeto.

Requisitos:
1. Identifica regras de negócio e cenários.
2. Inclui happy paths, boundary values, invalid inputs e exceptions.
3. Utiliza mocks para dependências externas.
4. Usa testes parametrizados quando adequado.
5. Define resultados esperados a partir dos requisitos.
6. Não alteres o código de produção sem autorização.
7. Executa os testes e apresenta os resultados, se possível.

Entrega:
- Ficheiros de teste.
- Cenários cobertos.
- Resultados da execução.
- Ambiguidades e possíveis defeitos.
